# iPhone: особенности и закрытые заранее баги

| Проблема на iPhone | Что сделано |
|---|---|
| Звук без нажатия запрещён; новый плеер нельзя включить из экрана блокировки | Один `<audio>` на всё приложение, станции меняются заменой адреса |
| `http://` потоки не играют на https-сайте | Только `https://` адреса |
| С `crossOrigin` радио без CORS молчит | `crossOrigin` не ставим |
| На экране блокировки вместо ⏮ ⏭ появляются «−10/+10 сек» | Обработчики перемотки сброшены, заданы `nexttrack` / `previoustrack` |
| Обложка на экране блокировки пропадает при смене потока | Обложка ставится ещё раз, когда пошёл звук; PNG 512×512 без прозрачности |
| Переключатель «бесшумно» глушит звук | `navigator.audioSession.type = 'playback'` (iOS 17+) |
| Быстрые нажатия «следующая» — ответ старой станции перебивает новую | У каждой команды номер; старые ответы игнорируются |
| «The operation was aborted» при смене станции | `AbortError` не считается ошибкой |
| Станция не отвечает | 15 с ожидания → запасной адрес → каталог radio-browser → пропуск. Если листали «следующая» — включается следующая станция, как плеер пропускает битый трек |
| Звук завис (метро, смена Wi-Fi ↔ LTE) | Если звук стоит 12 с — переподключение (до 3 раз), после `online` — сразу |
| После долгой паузы играет старый кусок и зависает | Пауза больше 8 с — подключаемся заново, к живому эфиру |
| Звонок / Siri ставят на паузу | Показываем «Пауза», кнопка ▶ включает заново |
| Громкость из кода на iPhone не работает | Ползунка нет — громкость кнопками телефона |
| Нажатие «теряется», если список перерисовался под пальцем | Перерисовка только при реальных изменениях |
| Двойной тап увеличивает страницу, страница ездит вбок при свайпе | `touch-action: manipulation`, запрет масштаба, `preventDefault` только для горизонтального свайпа |
| «Чёлка» и полоска снизу перекрывают кнопки | Отступы `env(safe-area-inset-*)` |
| Новая версия сайта не подхватывается в приложении с экрана Домой | При возврате в приложение проверяется версия; перезагрузка только когда радио молчит |
| После открытия приложения сразу играть нельзя | Последняя станция показывается на паузе, ▶ — включить |

## Что нельзя сделать в веб-приложении
- Название песни: большинство станций отдают его только в потоке (ICY) без CORS — браузеру не прочитать.
- Автозапуск при открытии — iPhone запрещает.
- Будильник / работа после закрытия приложения смахиванием — нет.
