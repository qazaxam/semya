# 6. История разработки

← [Возможности](05-features.md) · [Оглавление](README.md) · Далее: [Ограничения →](07-limits.md)

Всё сделано 22 ноября 2026 года за один день вместе с ассистентом Claude Code. Подробности каждого шага — в `git log`.

## Этапы
1. **Логины.** Выбрали схему `yurt01…yurt99` (тюркское «юрт» — родина/дом, понятно и в казахском, и в турецком). Логин неизменяем, понятное имя — отдельно.
2. **Каркас.** Vite + ванильный JS, OIDC-вход, Стена, Сообщения, PWA, свой логотип (шаңырақ), палитра в духе ретро-соцсетей.
3. **Публикация.** GitHub-репозиторий `qazaxam/semya`, Pages через Actions.
4. **Друзья, поиск, профиль, радио, кнопки ↻ и 🔍.**
5. **Мессенджер «как у всех»:** полноэкранный чат, статусы, даты, «печатает…», звуки, плашки, ответы, реакции.
6. **Уведомления в фоне:** рассыльщик на Cloudflare Workers.
7. **Медиа:** фото, видео, кружки, голосовые, файлы.
8. **Архив и документация.**

## Найденные баги и их причины (важно при правках!)
| Симптом | Причина | Исправление |
|---|---|---|
| matrix-js-sdk v45: нет `registerOidcClient` и др. | В v45 модуль OIDC переименован в `oauth`, API — класс `OAuth2` | [`src/auth.js`](../src/auth.js) на `OAuth2.registerClient`, `generateAuthorizationCodeGrantUrl`, `completeAuthorizationCodeGrant`; обновление токенов — встроенное (`oauthClientId` + `onTokenRefresh`) |
| Вход с `localhost` — «Dynamic registration failed» | account.matrix.org не принимает `http://localhost` как адрес web-клиента | Вход проверяем только на опубликованном сайте; понятная ошибка в коде |
| На телефоне старая версия сайта | Pages разрешает кэш ~10 мин; iPhone держит страницу в памяти | Проверка новой версии при открытии + перезагрузка «мимо кэша» (`?r=...`) |
| Писали не тем людям (`@yurt1` вместо `@yurt01`) | Опечатка в логине | Поиск показывает найденный аккаунт до добавления |
| «Добавить в друзья» будто не нажимается | Создание комнаты занимает пару секунд без отклика | Сразу «Отправляем…» |
| Страница масштабировалась | iPhone приближает поле ввода со шрифтом < 16px | `font-size: 16px` у полей, запрет масштабирования |
| Шапка уезжала при «потянуть» | Резиновая прокрутка iOS | `overscroll-behavior: none`, свой индикатор |
| Шторка конфликтовала с «назад» | Свайп от левого края — системный жест iOS | Открытие только кнопкой ☰ |
| Обложка радио с белыми углами | PNG со скруглением и прозрачными углами | Квадратные PNG (`icon-square-512.png`) |
| Чат «улетал» при открытой клавиатуре, сообщение «не отправлялось» | Фиксированная нижняя панель + клавиатура iOS | Чат на весь экран по `visualViewport`, мгновенный показ с часиками |
| Нажатия иногда не срабатывали | Список перерисовывался при каждом событии (печатает, прочитано) прямо под пальцем | Не перерисовывать, пока палец на экране; не перерисовывать без изменений |
| Отступ над клавиатурой | Учитывался отступ под «полоску» iPhone при открытой клавиатуре | Класс `kb` по фокусу поля |
| Ответы не показывались | В зашифрованных чатах `m.relates_to` лежит в незашифрованной «обёртке» | `ev.replyEventId` (берёт из wire content) |
| ↻ выключал радио | Полная перезагрузка страницы | `softRefresh`: перезагрузка только при новой версии |
| Уведомления не приходят в фоне | iOS замораживает веб-приложение | Web Push через рассыльщик |
| Радио: «The operation was aborted» | iOS прерывает `play()`, если звук был у другого плеера | Повтор попытки (`tryPlay`) |
| ▶ в кружке не по центру | Переносы строк в разметке + `white-space: pre-wrap` в пузыре | Разметка медиа без переносов, `white-space: normal` |
| Фото/файл выбирается, но не отправляется | iOS не шлёт `change`, если `<input type=file>` не в документе | Поле добавляется в документ перед `click()` |
