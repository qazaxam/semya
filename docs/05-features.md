## Вход и аккаунт
- «Войти» → страница account.matrix.org → возврат. Повторный вход не нужен: токены в браузере, access token обновляется сам (refresh token).
- Устройство называется «Юрт — браузер».
- Настройки: отображаемое имя, ключ восстановления (подтверждает устройство и открывает старую зашифрованную историю), выход.

## Разделы (меню ☰)
| Раздел | Что там |
|---|---|
| Моя страница | Профиль: большая аватарка-буква, имя, логин, число друзей, записи на Стене |
| Стена | Лента постов комнаты «Стена», новый пост, комментарии (треды) |
| Друзья | Заявки (принять/отклонить) и список друзей |
| Сообщения | Все чаты, непрочитанные, приглашения в группы |
| Радио | 8 турецких станций; играет фоном; управление с экрана блокировки (⏮ ⏭ — переключение станций) |
| Поиск | По логину (`yurt02`) или имени → «Добавить в друзья» |
| Настройки | Имя, ключ, уведомления и звуки, тест уведомления, архив, выход |

Шапка: 🔍 поиск, ↻ обновить. Профиль любого человека — нажать на имя/аватар.

## Чат
- Полноэкранный: шапка сверху, поле ввода прижато к клавиатуре.
- Статусы: 🕓 отправляется · ✓ доставлено · ✓✓ (синие) прочитано · «Не отправлено · повторить».
- Даты-разделители, «печатает…», анимация новых сообщений, кликабельные ссылки (без превью — ради приватности).
- **Ответ**: свайп по сообщению вправо или долгое нажатие → «Ответить». Цитата кликабельна.
- **Долгое нажатие**: реакции ❤️👍😂😮😢🙏, ответить, копировать, удалить (своё).
- **📎**: фото или видео из галереи/камеры, видео-кружок, файл.
- **🎤** (поле пустое): удерживать — запись, отпустить — отправить, увести влево — отмена.
- **Видео-кружок**: до 1 минуты, фронтальная/основная камера, сжатое качество (~6 МБ/мин).
- Фото сжимаются до 1600 px, геометки удаляются. Нажатие — на весь экран.
- В зашифрованных чатах вложения шифруются до отправки.

## Уведомления
- Пока приложение открыто: звук + плашка сверху (нажать — перейти в чат).
- В фоне и закрытом виде: Web Push через рассыльщик → уведомление «Имя — Новое сообщение» (текста нет: переписка зашифрована, сервер его не видит). Нажатие открывает нужный чат.
- Цифра непрочитанных на значке приложения.
- Тест: Настройки → «Прислать тестовое уведомление» (придёт через 10 секунд).

## Жесты
- Потянуть ленту вниз — обновить (на экранах-списках; страница не перезагружается).
- Меню открывается кнопкой ☰, закрывается свайпом влево или нажатием на затемнение. Свайп от левого края — системное «назад» iPhone.
