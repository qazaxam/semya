# Станции

Список — `src/stations.js`. Порядок в списке = порядок переключения «следующая».
«Следующая» листает станции того списка, из которого включили станцию (главный или «Популярные»), по кругу.

## Как добавить станцию
1. Найти адрес потока, только `https://` (подойдут `.m3u8`, `/stream`, `.mp3`, `.aac`).
2. Добавить объект в `MAIN` или `POPULAR`: `id` (латиницей, уникальный), `name`, `city`, `fm`, `color`, `urls`.
   Можно несколько адресов — запасные пробуются по очереди.
3. Для местной станции с ненадёжным адресом можно указать `rb` (имя в radio-browser) и `rbState` (область).
4. `npm run icons` — создаст обложку `public/art/<id>.png` для экрана блокировки.
5. `npm run build`, коммит, push.
