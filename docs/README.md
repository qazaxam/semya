## Карта кода
| Файл | Что делает |
|---|---|
| `index.html` | Страница радио (тёмная тема, настройки для «экрана Домой») |
| `src/main.js` | Экран: список, папка «Популярные», мини-плеер, большой плеер, свайпы |
| `src/player.js` | Плеер: подключение, запасные адреса, переподключение, экран блокировки |
| `src/stations.js` | Список станций |
| `src/label.js` | Буквы на плитке станции |
| `src/style.css` | Тёмная тема |
| `src/config.js` | Название, подпись, ссылка на архив |
| `scripts/icons.mjs` | PNG-иконки и обложки станций (`public/art/*.png`) |
| `public/` | manifest, иконки, обложки; `public/yurt/` — файлы архива |
| `yurt/` | Архив «Юрт» (работает, собирается вместе с радио) |
