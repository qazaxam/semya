## Устройство main.js (по разделам)
| Раздел в файле | Что делает |
|---|---|
| утилиты | `esc` (защита от HTML), `avatar`, время, `body()` — текст/медиа сообщения, `plain()` — короткий текст для превью |
| медиа в сообщениях | `mediaHtml()` — разметка фото/видео/кружка/голосового/файла |
| каркас | `layout()` — шапка, меню, `#view`, `#bar` (поле ввода), `#toast` |
| друзья | `friends()`, `friendRequests()`, `addFriend()`, поиск людей |
| радио | `playStation`, `tryPlay`, Media Session (экран блокировки) |
| экраны (`views`) | wall, post, chats, friends, user, radio, search, chat, settings. У экрана: `title`, `html`, `bar`, `refresh()` → HTML списка, `after()` |
| маршрутизация | `route()` по `location.hash`; `refresh()` — перерисовка списка, с защитой от перерисовки под пальцем |
| `patchList` / `hydrate` | Чат обновляется по ключам сообщений (не трогаем неизменённые, чтобы не прерывать видео/голос); `hydrate` скачивает и расшифровывает медиа |
| отправка медиа | `upload()` с прогрессом, выбор файлов, голосовые (удержание 🎤), видео-кружок |
| действия (`actions`) | все кнопки с `data-act="..."` |
| формы (`forms`) | все формы с `data-form="..."` |
| ответы/реакции/меню | долгое нажатие и свайп по сообщению, нижнее меню (`openSheet`) |
| входящие | звук + плашка + системное уведомление |
| автообновление | `hasUpdate`/`softRefresh`: ↻ не перезагружает страницу, если версия та же (радио не прерывается) |
| жесты | «потянуть вниз — обновить», закрытие меню свайпом |
| запуск | `boot()`: возврат с OAuth → старт клиента → подписки на события → push |

## Соглашения
- Кнопки и ссылки работают через делегирование: `data-act="имя"` → `actions.имя(el)`.
- Любой пользовательский текст выводится только через `esc()`.
- Новое, что легко настраивать, — в `config.js`.
