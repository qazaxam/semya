# 9. Инструкция для семьи

← [Архив](08-archive.md) · [Оглавление](README.md)

Эту страницу можно переслать родственникам.

## 1. Аккаунт
Вам выдадут логин вида **yurt05**. Регистрация — на https://account.matrix.org («Create account») или прямо со страницы входа.

## 2. Установка на iPhone
1. Откройте **Safari** (именно его) → адрес **qazaxam.github.io/semya**.
2. Должна открыться синяя страница «Юрт» с кнопкой «Войти». (Не путать с github.com — это другое.)
3. Внизу «Поделиться» → **«На экран „Домой“»** → «Добавить».
4. Дальше открывайте **только значок «Юрт»**. Нажмите «Войти», введите логин и пароль.

**Android:** Chrome → тот же адрес → ⋮ → «Добавить на главный экран».

## 3. Уведомления (iPhone)
1. В «Юрте»: ☰ → Настройки → **«Включить уведомления»** → «Разрешить».
2. Нажмите **«Прислать тестовое уведомление»** и сверните приложение — через 10 секунд придёт «Тест».
3. Если не пришло: Настройки iPhone → Уведомления → Юрт → включить.

## 4. Как пользоваться
- **Друзья:** 🔍 → логин родственника → «Добавить в друзья». Заявки — в ☰ → Друзья.
- **Сообщения:** пишите текст; 🎤 — удерживайте для голосового; 📎 — фото, видео-кружок, файл.
- **Ответить:** проведите по сообщению вправо. **Реакция:** удерживайте палец на сообщении.
- **Обновить:** ↻ сверху или потяните список вниз.

## 5. Новый телефон
На новом устройстве старые сообщения появятся после ввода **ключа восстановления**: ☰ → Настройки → «Ключ восстановления». Храните ключ в надёжном месте.
