# Юрт — документация проекта

**Начните отсюда.** Здесь всё, чтобы понять проект без исходной переписки с ассистентом: что это, где что лежит, как развернуть с нуля, что уже сделано и какие грабли собраны.

## Что это за проект
«Юрт» — закрытая семейная соцсеть в ретро-стиле начала 2010-х. Это **только веб-оболочка**: сервер — публичный Matrix-хоумсервер **matrix.org**, сайт лежит на **GitHub Pages**, своего сервера нет (одно исключение — маленький бесплатный «рассыльщик уведомлений» на Cloudflare).

Сайт: **https://qazaxam.github.io/semya/** · Код: **https://github.com/qazaxam/semya**

## Если вы новый разработчик (или новый чат с ассистентом)
1. Прочитайте [01-overview.md](01-overview.md) и корневой [`CLAUDE.md`](../CLAUDE.md) — там жёсткие правила проекта.
2. Разверните по [03-setup.md](03-setup.md).
3. Перед правками загляните в [06-history.md](06-history.md) — многие «странные» места в коде — это исправления конкретных багов iPhone.
4. Работаем мелкими шагами: правка → `npm run build` → коммит → `git push` (сайт обновится сам).
