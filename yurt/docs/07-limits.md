# 7. Ограничения и известные проблемы

## matrix.org (бесплатный аккаунт)
- Загрузка медиа: **до 500 МБ в сутки и до 2 ГБ за 28 дней** на аккаунт (по условиям fair use, 2025). С 2025 есть платные «премиум»-аккаунты с бо́льшими лимитами; условия могут меняться: https://matrix.org/homeserver/pricing/
- Лимит размера одного файла сервер сообщает после входа; приложение проверяет его само (`getMediaConfig`).
- Превышение → понятная ошибка «исчерпан бесплатный лимит».
- Ориентиры: фото ~0,3–0,5 МБ, голосовое ~0,4 МБ/мин, кружок ~6 МБ/мин, видео из галереи iPhone 50–150 МБ/мин (лучше кружки).
- Регистрация и вход — только через account.matrix.org (OIDC).

## iPhone / Safari
- Уведомления — только у приложения, добавленного на экран «Домой» (iOS 16.4+), после разрешения.
- Камера/микрофон: приложение со значка может спрашивать разрешение после каждого перезапуска.
- Первое нажатие на 🎤 может вызвать запрос разрешения — запись тогда не начнётся, нужно нажать ещё раз.
- iOS записывает MP4 (AAC/H.264), Android — WebM. Старые iPhone могут не проиграть WebM с Android.
- В Safari (не со значка) нет уведомлений, а память сайта (вход) у Safari и значка раздельная.

## Шифрование
- На новом устройстве старая зашифрованная история не читается, пока не введён **ключ восстановления** (Настройки).
- Текст сообщений не виден ни matrix.org, ни рассыльщику — поэтому в уведомлениях только имя отправителя.
- Превью ссылок выключены (иначе сервер видит, какие ссылки вы шлёте).

## Рассыльщик (Cloudflare)
- Бесплатный план: 100 000 запросов в сутки — с огромным запасом.
- Если Cloudflare недоступен — уведомления в фоне не придут, всё остальное работает.
