# 8. Архив переписок: выгрузка и будущий импорт

← [Ограничения](07-limits.md) · [Оглавление](README.md) · Далее: [Инструкция для семьи →](09-family-guide.md)

## Выгрузка (уже работает)
**Настройки → «Скачать архив»** — приложение листает историю всех чатов до начала, расшифровывает и скачивает два файла:
- `yurt-archive-ГГГГ-ММ-ДД.json` — полный архив для программ (формат ниже);
- `yurt-archive-ГГГГ-ММ-ДД.md` — тот же архив как читаемый текст.

Код: [`src/archive.js`](../src/archive.js).

### Важно про шифрование
- Расшифровывается всё, для чего у устройства есть ключи. Чтобы получить **всю** старую историю — сначала ввести ключ восстановления (Настройки), затем выгружать.
- Сообщения без ключа помечаются `"undecryptable": true`.
- **Архив НЕ зашифрован.** Хранить у себя (папка на Mac, личное облако, флешка).
- ❌ **Не класть в репозиторий `semya`** — он публичный. Файлы `yurt-archive-*` уже в `.gitignore`.
- Если нужен «бэкап через GitHub» — только **приватный** отдельный репозиторий (например `qazaxam/yurt-backup`, Private). Даже там лучше хранить архив в зашифрованном zip/7z с паролем.

## Формат `yurt-archive` версии 1
```json
{
  "format": "yurt-archive",
  "version": 1,
  "exported_at": "2026-11-22T12:00:00.000Z",
  "exported_by": "@yurt02:matrix.org",
  "rooms": [
    {
      "room_id": "!abc:matrix.org",
      "name": "Имя собеседника или комнаты",
      "encrypted": true,
      "members": [{ "user_id": "@yurt01:matrix.org", "name": "Папа" }],
      "messages": [
        {
          "id": "$событие",
          "ts": 1795320000000,
          "date": "2026-11-22T10:40:00.000Z",
          "sender": "@yurt01:matrix.org",
          "sender_name": "Папа",
          "type": "m.text",
          "text": "Привет",
          "reply_to": "$другое_событие",
          "thread_root": "$пост_на_стене",
          "media": {
            "mxc": "mxc://matrix.org/AbCd",
            "name": "photo.jpg",
            "info": { "mimetype": "image/jpeg", "size": 123456, "w": 1600, "h": 1200 },
            "encryption": { "key": { "k": "…" }, "iv": "…", "hashes": { "sha256": "…" }, "v": "v2" }
          }
        }
      ]
    }
  ]
}
```
Необязательные поля: `reply_to`, `thread_root`, `media`, `round_video`, `undecryptable`, `deleted`.

### Медиа из архива
Сами файлы в архив пока не входят — только ссылки (`mxc`) и **ключи расшифровки** (`encryption`). Скачать позже:
1. `GET https://matrix-client.matrix.org/_matrix/client/v1/media/download/<сервер>/<id>` с заголовком `Authorization: Bearer <токен>`;
2. если есть `encryption` — расшифровать библиотекой `matrix-encrypt-attachment` (`decryptAttachment(данные, {...encryption, url})`).
Следующий шаг развития: кнопка «Архив с медиа» → zip со всеми файлами.

## Импорт старых переписок (план, не сделано)
Matrix не позволяет обычному пользователю ставить сообщениям старые даты — каждое сообщение получит время отправки. Поэтому план такой:
1. Привести сырые данные (экспорт WhatsApp/Telegram/другое) к формату `yurt-archive` v1 — отдельный скрипт-конвертер под каждый источник в `scripts/import/`.
2. Вариант А (рекомендуется): создать комнату «Архив: Имя» и отправить в неё сообщения пачкой. Оригинальная дата — в поле `yurt.original_ts` и в начале текста (`[12.03.2019 14:22] Имя: …`). «Юрт» будет показывать такие сообщения с исходной датой.
3. Вариант Б: загрузить весь `yurt-archive.json` в комнату как один зашифрованный файл и сделать в «Юрте» просмотрщик архива — быстро и без «засорения» истории.
4. После импорта выгрузка (раздел выше) вернёт старое + новое в одном формате.

Что понадобится для старта: пример сырых данных (несколько строк) из каждого источника.
