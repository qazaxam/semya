# 1. Обзор и архитектура

← [Оглавление](README.md) · Далее: [Сервисы →](02-services.md)

## Схема
```
Телефон / браузер
  └─ сайт «Юрт» (GitHub Pages, статические файлы)
       ├─ matrix-js-sdk ──► matrix-client.matrix.org   (сообщения, синхронизация, медиа)
       ├─ вход ──────────► account.matrix.org          (OIDC/OAuth, логин и пароль вводятся там)
       └─ Web Push ◄────── yurt-push.qazaxam.workers.dev ◄── matrix.org (рассыльщик уведомлений)
```

## Жёсткие правила (полностью — в [`CLAUDE.md`](../CLAUDE.md))
- Всё бесплатно. Своего бэкенда нет. Исключение — рассыльщик уведомлений, см. ниже.
- **В репозитории нет паролей, токенов и секретов.** Токены живут только в браузере пользователя (localStorage/IndexedDB).
- Шифрование — только встроенный Rust-crypto matrix-js-sdk (`initRustCrypto`). Для вложений — готовая библиотека `matrix-encrypt-attachment`. Своей криптографии не пишем.
- Интерфейс на русском, сначала для телефона.
- Дизайн свой. Из ВКонтакте взята **только палитра цветов** и общий принцип тёмного бокового меню. Картинки, иконки и код ВК не используем.

## Главные решения и почему
| Решение | Почему |
|---|---|
| Matrix + matrix.org | Бесплатный готовый сервер с шифрованием «из коробки», открытый протокол, есть приложения Element X / FluffyChat для администрирования |
| Вход только через OIDC (account.matrix.org) | matrix.org больше не поддерживает вход паролем через API (`m.login.password`). Пароль вводится на странице matrix.org, не у нас |
| Vite + ванильный JS, без фреймворка | Проще, меньше зависимостей; Rust-crypto — это WASM, без сборщика ненадёжен |
| GitHub Pages + GitHub Actions | Бесплатно; каждый `git push` в `main` публикует сайт сам |
| `base: './'` в Vite и hash-маршруты (`#/chat/...`) | Сайт работает в любой папке Pages; не нужен серверный роутинг |
| PWA (значок на экран «Домой») | На iPhone уведомления и полноэкранный режим работают только у установленного веб-приложения |
| Рассыльщик уведомлений на Cloudflare Workers | iPhone «замораживает» веб-приложение в фоне; разбудить его может только Web Push, а его должен кто-то отправить. Worker бесплатный, ничего не хранит |
| Логины по схеме `yurt01`, `yurt02`… | Анонимно для чужих, структурно для своих; понятное имя задаётся отдельно (отображаемое имя) |

## Как устроено «соцсетевое» поверх Matrix
| В «Юрте» | В Matrix |
|---|---|
| Семья | Пространство (Space) с именем «Семья» |
| Стена | Комната «Стена»: пост = сообщение, комментарии = тред (`m.thread`) |
| Друзья | Личные диалоги (DM, `m.direct`). «Добавить в друзья» = создать DM с приглашением |
| Заявка в друзья | Приглашение в DM |
| Реакции | `m.reaction` (`m.annotation`) |
| Ответ на сообщение | `m.relates_to.m.in_reply_to` |
| Голосовое | `m.audio` + `org.matrix.msc3245.voice` |
| Видео-кружок | `m.video` + наш флаг `yurt.round: true` (в других клиентах — обычное видео) |

Названия «Семья» и «Стена» задаются в [`src/config.js`](../src/config.js).
