# Юрт — семейная сеть

Закрытая семейная соцсеть в ретро-стиле поверх Matrix (matrix.org). Сайт: https://qazaxam.github.io/semya/

📖 **Вся документация — в [docs/README.md](docs/README.md)** (архитектура, сервисы, развёртывание с нуля, карта кода, история багов, архив, инструкция для семьи).

## Быстро
- `npm install` — один раз
- `npm run dev` — локальный просмотр (вход работает только на опубликованном сайте)
- `npm run build` — сборка
- `git push` в `main` — публикация на GitHub Pages
- `src/config.js` — название, комнаты, радио, рассыльщик · `src/style.css` — цвета
