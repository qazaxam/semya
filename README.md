# Dalga — радио нашего края

Тёмное радио для iPhone: Power Türk, станции Амасьи, Токата и Турхала, папка популярных турецких станций.
Переключение «следующая / предыдущая» — как песни: на экране блокировки, в Пункте управления, свайпом.

Сайт: https://qazaxam.github.io/semya/ · Документация: [docs/README.md](docs/README.md)

Архив прежнего приложения «Юрт»: [yurt/](yurt/README.md) (работает по адресу `/semya/yurt/`).

## Быстро
- `npm install` — один раз
- `npm run dev` — локальный просмотр
- `npm run build` — сборка
- `npm run icons` — иконки и обложки станций (после изменения `src/stations.js`)
- `git push` в `main` — публикация
