# Проект: семейная мини-соцсеть (рабочее имя — semya)

Положи этот файл в корень репозитория. Claude Code читает его автоматически.

## Суть
Закрытая соцсеть только для родственников, делаем по фану. Сервер — публичный Matrix-хоумсервер **matrix.org**. Наш код — только веб-оболочка в ретро-стиле соцсетей начала 2010-х. Дизайн полностью свой: название, логотип, цвета, иконки. Чужой код, графику и узнаваемый стиль ВКонтакте/Facebook не копируем.

## Жёсткие ограничения
- Всё бесплатно, своего сервера и бэкенда нет.
- Хостинг — GitHub Pages, репозиторий публичный.
- **В репозитории нет никаких паролей, токенов и секретов.** Токены хранятся только в браузере пользователя (IndexedDB/localStorage).
- Шифрование — только встроенный криптомодуль matrix-js-sdk (Rust crypto, `initRustCrypto`). Своей криптографии не пишем.
- Интерфейс на русском языке, mobile-first: основной сценарий — телефон.

## Проверено (22.11.2026)
- `https://matrix-client.matrix.org/_matrix/client/versions` — **работает**.
- `https://account.matrix.org` — **работает**.
- matrix.org, app.element.io, app.cinny.in — **не открываются**. Это нас не касается: оболочка обращается напрямую к API.

## Ключевые технические факты
1. **Вход только через OIDC (Matrix Authentication Service).** На matrix.org вход и регистрация идут через account.matrix.org. Классический вход по паролю (`m.login.password`) не поддерживается, поэтому форму логин/пароль в оболочке НЕ делаем.
   - Порядок: discovery → `registerOidcClient` (динамическая регистрация клиента) → `generateOidcAuthorizationUrl` → редирект на account.matrix.org → возврат → `completeAuthorizationCodeGrant`. Всё это есть в matrix-js-sdk (`matrix-js-sdk/lib/oidc`).
   - Метаданные клиента: `client_name` — название соцсети; `client_uri` и `redirect_uris` — адрес на GitHub Pages (`https://<user>.github.io/<repo>/`); `application_type: "web"`; public client с PKCE.
   - Нужно сохранять refresh token и обновлять access token.
   - Для пользователя это выглядит так: кнопка «Войти» → страница matrix.org с логином и паролем → возврат в соцсеть.
2. **Медиа только через аутентифицированные эндпоинты** (`/_matrix/client/v1/media/...`). `<img src="mxc→http">` работать не будет. Делаем `fetch` с заголовком `Authorization`, затем `blob:` URL. Медиа из зашифрованных комнат дополнительно расшифровываем (AES-CTR по полю `file` из события) с помощью небольшой библиотеки для расшифровки вложений. Это нужно с версии 2, где появятся фото.
3. **Сборка: Vite + деплой на Pages через GitHub Actions.** Rust crypto в SDK — это WASM, без сборщика он ненадёжен. Pages: Settings → Pages → Source: **GitHub Actions**. `base` в vite.config — имя репозитория.
4. **Хранилище.** Состояние крипто и синхронизации хранится в IndexedDB. Устройству при входе даём понятное имя, например «Семья — браузер».
5. **Ключи.** После первого входа предлагаем настроить Secure Backup (ключ восстановления) и проверить устройство (верификация через другой вход). Без этого история зашифрованных сообщений на новом устройстве не прочитается — пользователю это нужно объяснить простыми словами.
6. **Превью ссылок** в зашифрованных комнатах выключены. Пока оставляем так.

## Структура в Matrix (создаю вручную через Element X или FluffyChat)
- Пространство (Space) «Семья», в нём комнаты:
  - «Стена»: пост — обычное сообщение, комментарии — тред (`m.thread`) к посту;
  - «Фото»: события `m.image`;
  - «Общий чат».
- Личные диалоги — обычные DM.
- Оболочка находит Space по имени или ID и показывает его комнаты как разделы.

## Версия 1 (MVP) — делаем сейчас
1. Каркас проекта: Vite, ванильный JS (или минимальный фреймворк, если правда нужен), один CSS со своей ретро-темой.
2. Вход и выход через OIDC (см. выше), автоматический повторный вход при открытии сайта.
3. Инициализация клиента: `createClient` → `initRustCrypto` → `startClient` (lazy loading участников).
4. **Стена**: лента постов (аватар, имя, время, текст), форма нового поста, раскрытие комментариев из треда и ответ в тред.
5. **Сообщения**: список личных диалогов и «Общего чата», окно переписки, отправка текста.
6. Простое шифрование: зашифрованные комнаты работают, есть кнопка настройки Secure Backup.
7. PWA: `manifest.json` (name, short_name, `start_url` и `scope` = база репозитория, `display: standalone`, theme_color, иконки 192 и 512 px, плюс maskable), `apple-touch-icon` 180 px. Service worker минимальный или вообще не нужен — офлайн нам не нужен.
8. Иконка и логотип — свои, простые, в SVG, из SVG генерируем PNG.

## Версия 2 (потом)

## Не делаем
Свой сервер, боты, хранение секретов в коде, своя криптография, копирование чужого дизайна.

## Как работаем
- Сначала план файлов, потом код небольшими шагами.
- После каждого шага: `npm run build` без ошибок, коммит.
- Объяснения — коротко и по-русски.
