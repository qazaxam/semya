# Группа «Цитаты» (дополнение)

Личная группа с цитатами и заметками: карусель «цитата за цитатой» без повторов, лента в новом порядке каждый день, «Мне нравится» → вкладка «Мне понравилось», поиск по записям, «Цитата» вверху Стены.

## Где данные
**Не в коде.** Записи лежат в личной зашифрованной комнате Matrix «Цитаты» (видна только владельцу). Лайк — реакция ❤️ на запись. Загрузка — кнопка «Загрузить заметки (.md)» в группе: разделы `## …` и записи `### …` становятся постами; повторная загрузка добавляет только новые.

## Как удалить полностью
1. Удалить папку `src/extras/quotes/`.
2. В `src/main.js` удалить все строки с пометкой `extras:quotes` (поиск по тексту).
3. Данные: в Element X выйти из комнаты «Цитаты» (или оставить — она никому не мешает).
4. `npm run build`, коммит, push.
